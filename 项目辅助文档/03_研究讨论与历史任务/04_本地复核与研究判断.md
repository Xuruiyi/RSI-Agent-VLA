## 3. 强 VLA 的讨论需要分任务分布

Harness VLA v5 表2的直接 VLA 标准 LIBERO 成绩为 95.3%；同文表3的 LIBERO-Pro 扰动成绩为 50.0%，组合系统为 72.1%（Codex）和 82.4%（CC）。组合系统同时使用工具和记忆，这些数字不能单独归因于在线推理，也不能直接移作本项目成绩。[论文原文](https://arxiv.org/html/2607.08448v5#S3.T3)

因此，接近饱和的判断应限定到标准任务。E1 同时需要标准任务的保持/误干预检查，以及扰动、重绑定、交接和组合条件。论文要解释动态 Agent 超过充分开发的冻结程序和简单监督的部分。

## 4. F2 的必要性与新颖性

Robo-COP 已在更新后保留历史、将阻止调用 VLA 的建议标为当前 checkpoint 下待验证并允许重测。[Robo-COP §3.3](https://arxiv.org/html/2610.09228v1#S3.SS3)

EmbodiedRSI 已包含假设驱动实验、信息价值选择及按后续收益学习记忆操作，实验阶段的机器人基础模型冻结。[EmbodiedRSI §3](https://arxiv.org/html/2610.10498v2#S3)

版本表、历史记忆和 VOI 的组合不足以确立新贡献。值得检验的窄命题是：技能入态、交接和调用结构能否预测真实模型更新会改变哪些协作决定，从而减少必要的再验证。

需分别证明三个环节：变化具有结构；方法能提前预测；预测能改善任务效用或真实验证成本。不能从“局部变化存在”直接推出“局部变化可预测”。

旧策略可能保持原成绩，却继续进行已无必要的接管、绕行或额外调用。进入条件可以是重要的成本/覆盖机会损失，无须等待组合系统总体退步。若旧策略适用或简单修订已足够，采用简单方案。

## 5. ρA 当前奖励的确定性偏好

[relation_learning.py](../../core/src/rsi_vla/relation_learning.py)中，两种动作是全保留和每个有媒体的事件保留一条引用；后者通过 `min(e["media"])` 选路径。奖励为：

```text
事件覆盖率 − .1 × 保留引用数 / 全部引用数
```

按当前构造，两种动作对有媒体事件的覆盖率都是1。全保留奖励恒为 .9；每事件一条的奖励必然不低于 .9，减少引用时严格更高。这是逐样本的目标结构推导，不是新运行结果。

该目标可以验证引用压缩与消费，无法判断留下的相机/帧是否更有诊断价值。近期保留其为压缩基线，区分引用减少、真实 payload/存储变化和诊断收益；后续用独立诊断或任务收益评价，不能用 `learned=true` 领取能力贡献。

## 6. ρC 可能截断自身后续反馈

当前 [relation_learning.py](../../core/src/rsi_vla/relation_learning.py)按 `task_key` 汇总 `bounded_experiment` 的 screening 全通过率；[cooperation.py](../../core/src/rsi_vla/cooperation.py)的 `fixed_research_step()` 在经验均值≤.5时返回 `defer`，该函数没有主动探索或随时间恢复的分支。

若新反馈必须经过同一门控，一次失败后可能形成“延后→无新反馈→持续延后”。这是一项有条件的机制风险，现有材料没有证明它已在真实运行中发生。

近期应保留原准入基线，在新任务中按算子、证据、版本和数据条件区分必要上下文，分开记录技术有效、筛选通过、性能、保持与成本，并提供有界探索或重新评估入口。探索不取消数据、技术或发布准入。先回放定位真实分歧，再对重要分歧做有界比较；评价同时计入节省的浪费与错过的改进。

## 7. 实验设计的补充

### E1 的臂必须对应实际决策能力

| 臂 | 操作定义 |
| --- | --- |
| D | 固定全任务指令、直接 VLA 闭环，无在线 Planner 或隐含动态路由 |
| S | 冻结技能顺序与切换条件，不重新规划 |
| R | 冻结条件策略，允许预定观察分支与恢复 |
| A | 在线生成或修订后续计划与调用 |

充分开发的冻结程序可能与 R 重叠，按实际行为报告，不把四个标签当成四种互斥算法类别。相同信息权限还需实际感知消费者支持，不能只在协议中写“同信息”。

### E2 四格检验交互，适应价值还需对照

B1 在 θ1 开发后冻结，两种 θ 使用同一个 B1 内容对象。实际版本绑定与 fallback 必须可辨认。

若 `Uij` 表示 θi 与 Bj 的独立评价效用，则：

```text
θ1 上的适应收益 = U11 − U10
固定策略交互   = (U11 − U10) − (U01 − U00)
```

交互不自动证明联合学习或某个反馈通道有效。B1 在 θ1 上开发本来就可能产生特化，应把“执行者不变、给予相同适应预算”的负对照提升为关键比较，区分升级特有适应和普通额外开发收益。

小样本未检出差异不等于简单方案足够。继续、简化和转向需结合最小有用收益、估计精度及实际成本；样本量不沿用历史示例。

### H3 考试冻结真正控制研究行为的状态

有效 ψ 包括实际影响研究选择的程序、提示、ρC 和检索规则；只固定 `psi_ref` 可能遗漏核心变化。事实记忆与策略内容先划分，记录修改来自模型、程序还是人工。共同事实库不强迫最终检索结果相同；拆分不兼容时限定为联合包结果。

首个考试可聚焦真实诊断与实验选择，在预留机制/任务族、共同起点与同预算下测独立收益。多个初态不能充当多条独立演化历史。
