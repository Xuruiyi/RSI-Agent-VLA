# 按需配置终端代理

选择实际监听的一个端口。原指南出现的 `8080`、`7897`、`6666`、`4457` 是不同本地配置的示例，不要连续覆盖执行。

```bash
export http_proxy=http://127.0.0.1:4457
export https_proxy="$http_proxy"
export HTTP_PROXY="$http_proxy"
export HTTPS_PROXY="$http_proxy"
export ALL_PROXY="$http_proxy"
export all_proxy="$http_proxy"

export no_proxy=localhost,127.0.0.1,.local
export NO_PROXY="$no_proxy"
```

这些变量只影响当前终端及其子进程。查看代理状态：

```bash
env | rg -i '^(http_proxy|https_proxy|all_proxy|no_proxy)='
```

关闭当前终端的代理时，同时清除大小写和 `ALL_PROXY`，避免残留：

```bash
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy
```

`no_proxy` 和 `NO_PROXY` 可以保留，用于绕过本地服务。服务选择与代理开关分别设置；使用 Anthropic 还是 DeepSeek 本身不决定网络是否需要代理。
