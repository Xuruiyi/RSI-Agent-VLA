## 2. 自由审查的取舍

输入：[自由审查 PDF](../项目辅助文档/01_决策与审查原件/RSI_VLA_Research_Review.pdf)，14 页。以下结论来自对问答、逻辑、一手资料或本地源码的复核；“建议”保留为本次工作设计，不回填成用户选择。

| 审查观点 | 处理 | 复核理由与适用边界 |
|---|---|---|
| 完整性与科研贡献分开验收 | 采纳 | 对应 Q01/Q17，系统运行无法单独证明专用机制优于现有方法 |
| 需求已包含失败+正常主动+预算 | 采纳并纠正旧状态 | Q12—14 已明确；Q24 只剩具体算法未定 |
| 先做完整闭环，同时筛查科学残余 | 初次采纳；现行顺序按 §8 | F 用已有材料分析问题；仿真适用分支经 G_F_sim 进入 P_sim，全局仍经 G_F 进入适用 P/V；不以主创新成立阻断工程 |
| 优先诊断证据/修复和升级后再适应 | 保留为可选实施次序，不选为主线 | Q10 开放比较；审查排序没有本项目效应/成本证据 |
| 四条具体候选可支撑原创算法 | 保留为假设 | 可写出问题，不等于已有残余或新规则；需强直接解法比较 |
| C1—C8 可定义完整系统 | 转成 SC1—SC8 工作验收并调整 | 原清单是审查建议；将首次闭环、核心功能、变化范围和真机分阶段，避免首次接入即承担全部实验 |
| 每类关系应有实际学习证据 | 采纳能力要求，校准实际变化要求 | Q06 允许不更新；不能强制每类每轮变化，也不能用 no-op 占位证明能学 |
| 新 θ 后 B 的重新认证是潜在创新 | 收窄 | Robo-COP 已有旧建议失效和记忆修订；候选须超过校准/重训/记忆修订 |
| 接管后反事实、标签缺失、视频缺失分别处理 | 采纳 | 三者的观测对象与识别条件不同；L0 可能已覆盖总体终局 |
| 交互差分可作为协同证据 | 仅作统计量 | 正交互不能单独识别反馈方向或专用规则作用，需通道干预 |
| H3 需共同起点、同记忆新问题考试 | 采纳并补充兼容条件 | ψ 与记忆可能共享表示；无法可比就限定结论 |
| 简单 VOI/保守区间/通用进化不是现成创新 | 采纳“组件存在不足以证明” | 系统机制和实证贡献仍开放，不推成只有新算法才有价值 |
| 受保护综合评分与长期锚点 | 采纳原则，保留数值未决 | 与 Q15 一致；不能以审查者选择替用户冻结权重 |
| 开放代码需要隔离和独立发布权限 | 按修改范围落实 | 新算法首次真机人工审批来自 Q16；不为初版搭全套通用搜索/安全平台 |
| RPent 单主 Runtime、独立 core、训练后端按需接入 | 采纳为工程方案 | 与减少重复框架的要求一致；源码只支持接入位置，实际联调仍需项目运行证据 |
| 第二动作类型只需服务于具体结论 | 限定范围后承接 V4 计划 | 保留有限迁移，不把全矩阵迁移或更多模型设成首次闭环依赖 |
